# S4 — Фото и медиа

## Цель
Галереи моделей: загрузка, порядок, отображение на сайте.

## Где хранится
- **KV** binding `PHOTOS_KV` (не R2)
- API: `/api/photos`, upload/reorder/delete
- Админка: `PhotoGalleryEditor`, страницы `/admin/brand/...`

## Делает
- Порядок фото (pointer drag в админке)
- Проверка, что фото видно на странице марки/модели
- Ключ модели: `photoKey(brandSlug, modelSlug)`

## Не делает
- Хостинг вне KV
- Массовое удаление без подтверждения

## Чеклист «готово»
- [ ] Фото на карточке модели
- [ ] Галерея на странице версии
- [ ] Порядок сохранён (не только локальный drag)
