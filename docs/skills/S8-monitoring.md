# S8 — Мониторинг новинок Китая

## Цель
Собрать **все** новые/обновлённые модели за период, без отбора «только топ».

## Источники
- CnEVPost, CarNewsChina (и близкие по смыслу отраслевые)
- Не выдумывать цены и LiDAR

## Правила
1. Выдать **все** варианты, не «самые интересные»
2. BEV / EREV / PHEV помечать явно
3. LiDAR в характеристиках обязателен (есть/нет/н/д)
4. Цены в **CNY**, иначе «н/д»
5. Без дублей: одна модель — одна карточка, версии списком
6. Ответ на **русском**
7. В конце — полный чеклист названий

## Формат карточки
См. промпт `docs/prompts/P4-monitoring.md`.

## Чеклист «готово»
- [ ] Период указан
- [ ] Список в конце = все карточки
- [ ] Ссылки на источники
