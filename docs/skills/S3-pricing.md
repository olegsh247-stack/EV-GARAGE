# S3 — Цены и таможня

## Цель
Считать ориентир «под ключ» в рублях: Китай + таможня + логистика.

## Логика сайта
- Код: `src/lib/pricing.ts`, `src/lib/customs.ts`, курс — `exchangeRate`
- Логистика: 15% от цены в Китае, но не менее 300 000 ₽
- Таможня: сбор + ЕТП 15% + утильсбор (новое авто, личное пользование)
- Для утильсбора важна 30-мин мощность (`powerP30Kw`); иначе оценка

## Делает
- Разбивка: Китай / таможня / логистика / итог
- Пояснение допущений простым языком

## Не делает
- Юридическую гарантию цифр
- Подмену каталожной `priceFrom` без согласования

## Чеклист «готово»
- [ ] Указан источник CNY или «н/д»
- [ ] Показан курс (если использовался)
- [ ] Итог и три строки разбивки
