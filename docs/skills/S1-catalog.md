# S1 — Каталог

## Цель
Добавлять и обновлять бренды, модели и комплектации (trims) в каталоге EV-GARAGE.

## Делает
- Новая марка / модель / версия
- Правка имени, slug, описания, цветов
- Согласование структуры с типами в `src/data/cars.ts` и таблицами D1

## Не делает
- Расчёт таможни (→ S3)
- Загрузку фото (→ S4)
- Деплой (→ S7)
- Поиск новостей (→ S8)

## Данные
- Иерархия: **Brand → Model → Trim[]**
- Цвета: `exteriorColors`, `interiorColors` на уровне модели
- Источник правды в проде: **D1** (`getBrands` в `src/lib/catalog.ts`)
- Fallback: `src/data/cars.ts`

## Чеклист «готово»
- [ ] slug латиницей, стабильный URL
- [ ] хотя бы одна версия (trim)
- [ ] тип силовой установки указан
- [ ] не дублирует существующую модель
- [ ] после записи — проверка страницы `/brand/{slug}`
