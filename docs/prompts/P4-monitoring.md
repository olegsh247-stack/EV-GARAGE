# P4 — Мониторинг новинок (S8)

```
Мониторинг новинок электромобилей Китая для EV-GARAGE.

Источники: CnEVPost, CarNewsChina (и аналоги по смыслу).
Период: [например последние 7 / 30 дней].

Правила:
1) Выдай ВСЕ найденные варианты, не только «самые интересные».
2) Включи BEV, EREV, PHEV; отметь тип.
3) В характеристиках обязательно блок LiDAR (есть / нет / неизвестно + тип если есть).
4) Цены в CNY, если есть; иначе «н/д».
5) Без дублей (одна модель = одна карточка, версии — списком).
6) Язык ответа: русский.

Формат каждой карточки:
- Бренд / Модель
- Тип кузова, мест
- Тип силовой установки
- Версии (имя, запас хода, мощность, цена CNY)
- LiDAR
- Коротко «что нового»
- Ссылки на источники

В конце: полный список названий всех моделей из ответа (чеклист).
```
